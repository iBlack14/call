  1. Descarga el APK con el botón de arriba.
  2. En Android: Ajustes → Seguridad → Instalar apps desconocidas → Activar para tu navegador.
  3. Abre el archivo descargado e instala.
  4. Abre Phone-VC, escanea el QR o ingresa el código de sesión.
  5. Activa Phone-VC como marcador por defecto dentro de la app para poder colgar llamadas.
