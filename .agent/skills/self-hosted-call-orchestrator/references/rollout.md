# Rollout Phases

## V1

- Android workers with SIMs
- backend queue
- one active outbound contact at a time
- callback derivation instead of live transfer
- dashboard visibility for workers, active contact, and callback queue

## V2

- richer disposition workflow
- transcript summary
- advisor assignment rules
- better retry policies
- worker health checks

## V3

- PBX or GSM gateway
- live transfer
- hold audio
- advisor SIP extensions
- queue handoff automation
